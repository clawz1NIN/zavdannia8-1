# Навчальний проєкт - Завдання 8.1

Сучасний навчальний сайт-портфоліо, створений на базі Vite + React + Tailwind CSS.

## 🚀 Технології

- **React 18.3** - бібліотека для побудови інтерфейсу
- **Vite 5.4** - швидкий інструмент збірки
- **Tailwind CSS 3.4** - utility-first CSS фреймворк
- **React Router 6.26** - маршрутизація
- **PostCSS & Autoprefixer** - обробка CSS

## 🎯 Розділи сайту

1. **Інфографіка або анімоване пояснення фізичного явища** (`/physics`)
2. **Навчальне відео з ШІ-озвученням математичної задачі** (`/math-video`)
3. **Короткий історичний огляд події або постаті** (`/history`)
4. **Алгоритм для логічної задачі з візуалізацією блок-схеми** (`/logic`)
5. **Презентація про вплив технологій на суспільство** (`/technology-presentation`)
6. **Короткий науково-фантастичний твір** (`/scifi-story`)
7. **Аналіз достовірності інформації, згенерованої ШІ** (`/ai-accuracy-analysis`)
8. **Казка для молодших учнів про "розумні" пристрої** (`/smart-devices-tale`)

## 🛠️ Встановлення та запуск

### Встановлення залежностей
```bash
npm install
```

### Запуск dev-сервера
```bash
npm run dev
```
Сайт буде доступний за адресою: `http://localhost:5173/`

### Збірка для продакшену
```bash
npm run build
```

### Попередній перегляд збірки
```bash
npm run preview
```

## 🎨 Особливості дизайну

- **Адаптивний дизайн** - коректно відображається на всіх пристроях
- **Мінімалістичний стиль** - чистий та сучасний вигляд
- **Hover-ефекти** - інтерактивні елементи з плавними переходами
- **Кольорове кодування** - кожен розділ має свій колір
- **Іконки-емодзі** - візуальна ідентифікація розділів

## 📝 Компоненти

### Layout
Загальний макет сайту з header та footer.

### Header
Навігаційна панель з логотипом та меню.

### Footer
Підвал з інформацією про проєкт.

### Card
Картка для відображення розділу на головній сторінці.

## 🔄 Маршрутизація

Всі маршрути налаштовані в [`App.jsx`](src/App.jsx):
- `/` - Головна сторінка
- `/physics` - Фізика
- `/math-video` - Математика
- `/history` - Історія
- `/logic` - Логіка
- `/technology-presentation` - Технології
- `/scifi-story` - Наукова фантастика
- `/ai-accuracy-analysis` - Аналіз ШІ
- `/smart-devices-tale` - Казка
- `*` - 404 сторінка

## 📊 Дані

Всі дані про розділи зберігаються в [`src/data/sections.js`](src/data/sections.js). Це дозволяє легко додавати нові розділи або редагувати існуючі.
